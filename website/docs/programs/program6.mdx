# Side-by-side Graphics

This program shows how to place multiple images side-by-side with individual captions using the `subcaption` package.

## Source Code

```latex
\documentclass{article}
\usepackage{graphicx}
\usepackage{subcaption}
\begin{document}
	\begin{figure}[htbp]
		\begin{subfigure}[b]{0.45\textwidth}
		\centering\includegraphics[width=\textwidth]{vcet_logo.png}
		\caption{Logo of the College}
			\label{Fig:Image}
		\end{subfigure}
		\hfill
	\begin{subfigure}[b]{0.4\textwidth}
	\centering\includegraphics[width=\textwidth]{vtu.jpeg}
	\caption{Logo of the University}
	\label{Fig:Image}
\end{subfigure}
		
	\end{figure}
\end{document}
```
