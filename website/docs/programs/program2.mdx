# Abstract/Summary Layout Design

This program shows how to design an abstract or summary layout in LaTeX using the `abstract` environment.

## Source Code

```latex
\documentclass{article}
\renewcommand{\abstractname}{Abstract}
\begin{document}
	\begin{abstract}
		Latex-Tutorial is the Beginner course to understand about the Latex language it is Used to create Professional reports ,resumes,documents from this tutorial you not only gain the Knowledge about the Latex You also typed your first latex program by the end of this.
	\end{abstract}
\end{document}
```
