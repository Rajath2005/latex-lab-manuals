# Document with Sections, Headers & Footers

This program demonstrates how to create a LaTeX document with sections, subsections, and custom headers/footers using the `fancyhdr` package.

## Source Code

```latex
\documentclass{article}
\usepackage{fancyhdr}
\pagestyle{fancy}
\fancyhf{}
\lhead{LaTeX}
\renewcommand{\footrulewidth}{0.4pt}
\lfoot{VCET\hfill\today\hfill \thepage}
\begin{document}
	\begin{center}
		\huge{Technical Writing Using LaTeX}\\[1.5em]
		\LARGE{Rajath Kiran A}\\[1.5em]
	\end{center}
	\section{Introduction}
	Latex-Tutorial Provides the Step by step lessons to Learn the Latex Language.It allows you to create a beautiful documents,reports,resumes and etc through easy and simple Tutorial.
	\section{Distribution} 
	\subsection{Windows}
	\begin{itemize}
		\item MikeTex
		\item Text Studio Editor
	\end{itemize}
	\subsection{Linux}
	\begin{enumerate}
		\item Latexila
		\item Text Studio Editor
	\end{enumerate}
\end{document}
```
